# As-Endorsed

Retrieval over insurance policies **as they currently read**. A policy is a base form plus a stack of endorsements that replace, delete and add clauses; this system resolves that stack at ingest and answers from the resolved policy, citing the clause on the actual form page.

Pick an account, ask a question, click a citation. Source and results: https://github.com/Ammarbit/as-endorsed
